# 收紧朋友圈文案默认长度

## Goal

将赛先生每日朋友圈文案从当前偏长、三段六行的默认形态，调整为接近用户给定案例的简洁阅读节奏：新闻事实、一个家长教育观点、一个赛先生教学方式，便于在朋友圈快速阅读。

## Confirmed Facts

- 当前默认规则为正文不超过 300 汉字、恰好三段六行、6--12 个 emoji；规则与提示词位于 `backend/app/domain/copy_generation.py` 和 `backend/app/application/services/copy_generation.py`。
- 当前长度、emoji 与段落格式均为 warning，可触发一次修复，但不会单独阻断素材包或投递。
- 新闻来源与原文链接由系统根据绑定证据追加，正文生成节点不得自行输出或替换它们。
- 用户只要求先在本地查看效果，不部署服务器、不发送企业微信。

## Requirements

1. 新默认文案策略要求正文主体目标为 180--240 汉字，超过 260 汉字生成 `copy_length` warning 并进入最多一次压缩修复。
2. 正文采用 2--3 个自然段，不强制每段两行、段首段尾 emoji 或固定空行数量；每段应保持完整自然句。
3. 正文包含 2--5 个 emoji，作为点缀而非替代解释。
4. 提示词应明确只保留一个新闻核心事实、一个面向家长的学习价值、一个与赛先生教学方式相关的解释，避免叠加课程年龄、体系介绍和多个卖点。
5. 保留新闻切入、系统追加的来源和原文链接、末行 2--3 个标签且首位固定为 `#赛先生科学`。
6. 长度和格式问题继续是 warning；修复后仍不符合也不得仅因此拒绝素材包或投递。

## Out Of Scope

- 不修改服务器配置、镜像或运行中的定时任务。
- 不发送企业微信消息，不修改历史素材包。
- 不改变证据绑定、来源页脚、品牌检索、生图或选题逻辑。

## Acceptance Criteria

- [ ] 本地版本元数据能区分新旧文案策略，避免重解释历史生成结果。
- [ ] 生成和审计提示词都明确短文目标、结构、emoji 目标与压缩修复行为。
- [ ] 确定性校验对超过 260 汉字、emoji 不在 2--5、段落不在 2--3 时给出 warning，不产生单独硬阻断。
- [ ] 更新相关单元测试，覆盖短文策略与旧版本兼容。
- [ ] 使用当天“智慧校车”新闻执行一次本地真实预览，向用户展示正文、字数和校验结果。
