# Restore tiered science and technology news priority

## Goal

把刚上线的“科学/AI 教育硬筛选”改为分层优先策略：教育部发布的科学教育、AI 教育、科技教育及科创人才培养相关新闻拥有最高优先级；其他来源的科学/AI/科技教育、白名单赛事、科技特长生、强基计划、综合评价等内容拥有高优先级；机器人、人工智能、重大科研成果等前沿科技突破仍可进入候选并参与正常排序。

## User value

内容运营既能稳定抓住与教育和产品最相关的新闻，也不会错过机器人、AI 和重大科研突破等值得传播的前沿科技内容；教育部权威发布在每日选题中获得清晰、可解释的最高优先权。

## Confirmed background

- 上一任务 `08-13-science-education-source-priority` 引入了 `science-ai-education-v1`，目前新活动 source version 只持久化科学/AI 教育合格内容。
- 当前 `.5` 评分版本对范围外事件加入 `outside_science_ai_education_scope` 硬否决，并关闭了教育部来源优先；两者均与本次用户确认的产品意图冲突。
- 教育部来源已携带 `moe-science-top1-v1`，现有 `science-policy-priority-v2` 可识别科学教育、AI 教育、机器人教育及政策行动词，但当前 `.5` 不启用该优先规则。
- 当前产品决定：AI 教育不是硬筛选；科学教育、AI 教育、科技教育是优先内容；机器人、人工智能、重大科研成果等前沿科技突破是正常候选；教育部发布的科学教育、AI 教育、科技教育相关新闻最高优先。
- 补充关注词为：`白名单赛/白名单赛事`、`科技教育`、`科技特长生`、`强基计划`、`综评/综合评价`、`人工智能`。这些词是分层识别信号，不是脱离语境的通行证。
- 本任务不修改 `reports/science-ai-content-upgrade-roadmap-2026-08-13.tex` 或 PDF。

## Requirements

### R1. Tiered editorial cohorts

- 规则必须确定性识别并解释三个内容层级：
  1. `ministry_education_priority`：教育部来源发布，且内容属于科学教育、AI 教育、科技教育、机器人教育、白名单赛事或科创人才培养/升学路径等教育主题；
  2. `science_technology_education_priority`：其他合格来源发布的科学教育、AI 教育、科技教育、STEM/STEAM、科学素养、青少年科创实践，以及白名单赛事、科技特长生、强基计划、综合评价等科创人才培养/升学路径内容；
  3. `frontier_science_technology`：不具备教育语境，但属于机器人、人工智能、重大科研成果或其他明确前沿科技突破的内容。
- 泛教育、泛商业、融资、营销软文、消费电子、无实质突破的一般企业发布不得因宽化规则进入候选。
- `白名单赛`、`科技特长生`、`强基计划`、`综评/综合评价`命中时，招生广告、培训导流、录取承诺、分数线聚合和标题党不得仅凭关键词入选；白名单身份、政策变化和招生规则必须有可核验来源。
- 三个层级是抓取探测和选题排序信号，不得成为事实证据或品牌事实。

### R2. Acquisition is broad enough but remains bounded

- 发布新的不可变抓取相关性版本；保留 `science-ai-education-v1` 与所有旧 source version 的回放能力。
- 抓取列表的标题排序顺序为：科学/AI/科技教育直接命中、前沿科技突破直接命中、标题中性正文探测；产品适配只在同层内做软排序。
- 详情页使用标题加最多 6,000 个规范化正文字符复核。持久化资格为“教育优先内容或前沿科技突破”，不再要求教育语境。
- 仍然使用现有 scan/item 上限、时效性、host/path/DNS/响应限制、限速、租约、重试、快照与幂等；禁止验证码、WAF、代理轮换或其他绕过。
- extraction metadata/observation 保存规则版本、内容层级、原因码、教育相关性、前沿科技信号、产品方向、正文边界以及过滤/延后计数。
- 发布新的不可变产品适配版本，在原六个方向上补充“白名单赛事—科技特长—强基/综评—科创人才路径”匹配；不能修改或重新解释 `product-matrix-fit-v1`。

### R3. Ministry education news has highest selection priority

- 新评分版本必须重新启用教育部内容优先，并扩展其主题范围，至少覆盖教育部发布的科学教育、AI 教育、科技教育、机器人教育、白名单赛事、科技特长生、强基计划和综合评价相关新闻。
- 教育部主题优先不再要求标题同时出现“通知/方案/行动/规划”等政策动作词；课程、实践、部署、成果、报道等实质相关新闻均可命中。
- 最高优先只适用于实际携带教育部受控来源策略的事件；不能仅凭标题出现“教育部”或转载来源文字伪造。
- 最高优先仍不得覆盖事实/证据不合格、隐私/法律/安全不确定、禁用营销、重复窗口、过期等现有硬否决。
- 最高优先不需要先达到普通数值选题阈值；只要命中教育部教育主题优先规则且没有任何硬否决，即可进入最高优先组。
- “教育部发布”必须来自受控教育部 source version 的持久化策略元数据；主题资格必须由标题和已治理摘要中的实际内容判断。

### R4. Education relevance becomes priority, not veto

- 删除新运行中的 `outside_science_ai_education_scope` 硬否决语义；历史 `.5` 配置、分数和解释继续按原快照回放。
- 科学/AI/科技教育相关性必须提高数值分或优先组，但零教育相关性不得否决合格的前沿科技突破。
- 产品矩阵适配保持有上限的软加分，不能覆盖任何真正的硬否决，也不能让泛商业/泛 AI 内容获得候选资格。
- 前沿科技内容必须具备明确主题和突破/进展语义；仅出现“AI”“机器人”“科学”等单个词不足以入选。
- `人工智能`必须按语境分流：人工智能教育进入教育优先层，实质人工智能突破进入前沿科技层，泛 AI 商业/融资/算力/营销内容仍不入选。

### R5. Explainability and compatibility

- 每个抓取候选和选题分数必须可解释：内容层级、教育命中、前沿科技命中、产品方向、教育部优先是否应用、总分、阈值、硬否决和排名均可从持久化/API 回读。
- 新规则和评分配置必须发布新版本，不能修改 `science-ai-education-v1`、`.5` 或历史快照语义。
- 不新增数据库迁移或公共 API 形状；优先复用现有 JSON metadata、feature maps、config snapshot 和 explanation。若实现发现必须变更 schema/API，先回到规划评审。
- 英文证据、中文治理事实、品牌上下文分离及人工审核边界保持不变。

## Acceptance criteria

- [x] AC1: 固定中英双语样本能稳定区分教育部教育优先、一般科技教育优先、前沿科技突破和范围外内容，并输出稳定原因码。
- [x] AC1a: `白名单赛/白名单赛事`、`科技特长生`、`强基计划`、`综评/综合评价`拥有稳定的科创人才路径原因码；对应的培训营销、保录/保过、分数线聚合和泛招生反例不能仅凭关键词入选。
- [x] AC2: 机器人/AI/重大科研突破在没有教育语境时仍可进入新候选池；融资、营销、普通企业发布和仅有宽泛科技词的反例不能进入。
- [x] AC3: 同一发现列表反复执行时，三层标题顺序、有界正文探测、候选集合和审计计数完全一致；不以无关内容补足 quota。
- [x] AC4: 教育部受控来源的科学教育、AI 教育、科技教育、机器人教育及白名单赛事/科创人才路径新闻进入最高优先组；其他来源同题新闻只获得一般教育优先。
- [x] AC5: 教育部最高优先可以越过普通数值阈值，但不能覆盖任何现有事实、安全、法律、重复或时效硬否决；非教育部内容仍必须达到正常阈值。
- [x] AC6: 新评分中，零教育相关但合格的前沿科技突破不再得到范围外 veto；科技教育内容正常高于同质量前沿科技内容。
- [x] AC7: 历史 `science-ai-education-v1` source version 和 `.5` 评分快照继续按原硬边界/否决语义读取和回放；新运行使用新不可变版本。
- [x] AC8: 抓取、选题、持久化、API explanation、Compose、doctor、前后端与完整质量门通过；PDF 报告无改动。

## Out of scope

- 修改或重新生成 PDF 报告。
- 新增/激活更多信源，或改变 CAST、EdSurge 的 pending 状态。
- 自动发布社交媒体、调整三时段推送、文案字数或 IP 数字资产。
- 通用网页搜索、浏览器自动化、验证码/WAF/代理绕过。
- 用 LLM 决定抓取资格或最终数值分数。
