# IP 资产演示加固

## Goal

在不重做现有编辑感视觉、不改变无鉴权公司内网边界的前提下，把 IP 数字资产中心收口为一条稳定、快速、容易讲清楚的现场演示链路：登录、自然语言找图、选择与收藏、AI 辅助识别上传、翻页相册、参考图生图和个人素材归集。

## Background and Confirmed Facts

- `/ip-assets`、`/ip-assets/create`、`/ip-assets/flipbook` 已是独立站点，不挂载到共享开发控制台。
- 现场检查的 42 张原图合计约 168 MiB；浏览器首轮可请求约 156 MiB 原图，且预览响应为 `Cache-Control: private, no-store`，重复打开会重新传输和解码。
- 文本检索的前两项能够命中“小赛开心”意图，但当前一次展示 16 项并直接显示约 3%–16% 的原始余弦相似度，容易让正确结果看起来不可信。
- `generation_available` 只证明生图 provider 已配置，现有合同明确不把它当作独立 worker 心跳；真实演示运行时必须通过外部预检确认 API、PostgreSQL、MinIO 和 worker。
- 登录页只是当前标签页的展示门禁；浏览器本地名片仍是不可信、不可恢复的个人素材分组，不升级为真实鉴权。
- 翻页动画本身已经修复，但 1440×1000 视口中的上一页/下一页按钮位于预览舞台下方，需要滚动。
- 现有 `ip_asset_derivatives` 表已经为 `thumbnail` 预留持久化结构，但当前列表卡仍直接加载原图。

## Requirements

### R1 — 轻量且可缓存的图库缩略图

- 为共享和当前名片可访问的 `ready` 资产提供固定版本的最大边 640px WebP 缩略图；不放大原图，保留透明区域和比例。
- 缩略图必须由已经校验的不可变原图生成，按策略版本与源 SHA-256 持久化到现有私有对象存储和 `ip_asset_derivatives`，并在并发首次请求时幂等复用。
- 列表卡、排行榜和共享参考图库使用 `thumbnail_url`；详情、原图下载、个人私有媒体和翻页相册继续使用现有受控 `preview_url`/下载合同。
- 缩略图返回强 ETag 与版本化长期私有缓存；原图下载继续 `no-store`，不得把私有对象位置或校验摘要暴露给浏览器。
- 共享图库和个人列表首批最多请求 16 项，保留现有游标“继续装载”行为，不一次装载全部 42 张。

### R2 — 演示友好的检索呈现

- 搜索框提供三条可点击的示例问题，点击后必须写入输入框并给出可感知反馈，不自动发起隐藏请求。
- 文本与以图搜图结果默认限制为 8 项，保留现有混合检索、明确过滤器和降级语义。
- 结果卡不再显示原始低百分比，也不在解释中复制数值相似度；存在向量证据时显示“含画面语义线索”，并保留真实元数据匹配理由。
- 语义-only 命中必须描述为“画面语义相关”，不得误称为文字或分类匹配。

### R3 — 选择、相册与移动首屏反馈

- 图库卡片的选择控件显示“选择/已选”文字状态，整张卡仍保留独立预览与收藏操作，状态不能只依赖颜色或圆点。
- 选择后操作条继续显示准确数量和 2–20 张相册规则，并突出“制作翻页相册”。
- 翻页相册的上一页/下一页按钮悬浮在预览舞台左右两侧，在常见桌面首屏内可见；键盘、触摸、动画锁和 reduced-motion 合同保持不变。
- 900px 以下图库必须先展示资产，再展示下载排行；排行榜不再抢占移动端第一屏。

### R4 — 低摩擦演示名片与创作示例

- 本地名片对话框保留手动显示名称/部门输入，同时增加明确的“一键使用演示名片”动作，使用固定安全标签完成同一个 retry-safe bootstrap 流程。
- 一键名片仍生成浏览器随机 token，只保存服务端摘要，并明确“非身份认证、仅当前浏览器、无恢复”；不得存储登录密码或把展示门禁升级为后端鉴权。
- AI 创作画面描述提供“载入示例简报”动作，使用现有受控角色、类型和参考图流程；不自动提交、不调用 provider。

### R5 — 真实演示预检

- 提供一个只读的演示预检命令，检查 API 能力、PostgreSQL、MinIO、恰好一个 IP worker 容器/进程状态、图库至少一页、缩略图响应与一次只读文本检索。
- 预检必须明确区分“provider 已配置”和“worker 当前运行”，不得创建生成任务、增加下载计数、上传资产、打印凭据/完整提示词/对象位置或修改业务状态；首次缩略图检查只允许幂等生成确定性的派生缓存。
- 本地运行手册和 Make 入口必须给出演示启动、预检、站点 URL 和演示路径。

### R6 — Compatibility and Scope Safety

- 保留现有无鉴权内网边界、资产不可变性、SHA-256 去重、个人私有结果、显式共享、原图下载计数、语义降级、生成幂等与 worker lease fencing。
- 不伪造 worker 在线、搜索置信度、下载排行榜或生成成功；不写入演示下载数种子。
- 不修改共享开发控制台、新闻采集任务、公众号流程或现有用户未提交改动。

## Acceptance Criteria

- [x] AC1: 冷启动共享图库首批最多 16 张，卡片请求版本化 640px WebP 缩略图而非原图；第二次请求命中长期私有缓存合同。
- [x] AC2: 同一资产并发首次缩略图请求只得到一个策略版本记录和一个已验证内容寻址对象；源 SHA 或策略不匹配时拒绝复用。
- [x] AC3: 详情、原图下载、个人私有预览和翻页相册访问保持原有权限、质量和下载计数语义。
- [x] AC4: 三条示例问题可键盘操作并只填充输入；文本/图片搜索最多展示 8 项，界面和解释均不出现原始相似度百分比或小数。
- [x] AC5: 混合结果仍保留真实匹配理由；有向量证据时显示定性语义线索，语义-only 命中不会被描述成文字匹配。
- [x] AC6: 卡片选择显示文字反馈，2–20 张操作条保持准确；1440×1000 与 390px 下相册上一页/下一页均在舞台内可见且原有鼠标、触摸、键盘、锁定和 reduced-motion 测试通过。
- [x] AC7: 900px 以下图库资产先于排行榜出现，首屏不再被下载排行占满。
- [x] AC8: 名片对话框可一键建立“演示用户 / 品牌中心”本地名片，也可手动填写；两条路径使用同一随机 token、同一后端 bootstrap 和同一边界提示。
- [x] AC9: 创作页可一键载入示例简报但不会自动提交或调用 provider。
- [x] AC10: `make ip-asset-demo-preflight` 只读验证 API、基础设施、单 worker、图库、缩略图和检索，并在任一项不满足时非零退出且给出安全修复提示。
- [x] AC11: 后端单元/集成焦点测试、OpenAPI 生成合同、前端 IP 资产测试、可访问性、ESLint、严格 TypeScript、Prettier、构建和真实桌面/移动浏览器演示回归通过。

## Key Decisions

- 使用现有 `ip_asset_derivatives` 持久化缩略图，不引入新表或每次请求动态重编码。
- 不新增未经证明的 UI worker 心跳；实时 worker 状态由演示预检读取实际运行环境，页面继续诚实区分 provider 配置与后台领取。
- 用一键“演示名片”减少第二身份步骤，不复用或保存登录密码，也不暗示员工身份。
- 不伪造排行榜数据；演示时通过真实下载自然产生计数。

## Out of Scope

- SSO、用户名密码后端认证、角色权限、跨设备名片恢复或公网部署。
- 搜索模型重训、embedding provider 替换、人工标注平台或新的向量索引。
- worker 心跳表、任务进度百分比、队列位置、预计耗时或 provider 成本面板。
- 伪造/批量写入下载排行、自动创建生成任务、自动上传或自动共享。
- 保存/分享翻页相册、PDF/视频导出或修改翻页引擎。
