# 真实预览链路与展示页

## Goal

按正常生产链路真实生成一次新闻选题、家长朋友圈文案和品牌 IP 图片；结果允许写入当前
本地开发数据库和 MinIO，同时导出为本地预览资料，并通过前端页面完整展示效果。当前验收
不向真实销售发送；正式产品链路在素材包通过后由后端通过企业微信自建应用发送给一个指定
销售。

## Confirmed Intent

- 这次是效果验收，不是正式日生产，但允许把结果写入当前本地开发数据库和 MinIO。
- 必须看到真实生成的文案和图片，而不是 fake provider 或静态样例。
- 图片继续使用公司 IP 视觉资料和现有内容驱动提示词；文案继续使用教育部/权威来源、
  品牌检索、智谱生成、验证和审计逻辑。
- 页面应展示选题解释、新闻来源、完整朋友圈文案、标签、图片、审核状态和失败原因；不
  提供自动发送企业微信、朋友圈或其他社交平台的按钮。
- 正式生产分发的唯一目标是一个配置好的企业微信销售 `userid`；前端只是观看和验收界面，
  不承担发送职责。当前预览任务不触发真实发送。
- 教育部 Top 1 优先仅适用于直接推动科学教育、科创教育、人工智能教育或机器人教育的
  政策、行动、指南、方案、通知、标准或实施部署；其他教育部新闻只能按常规评分参与。

## Requirements

1. 提供一个可重复执行的测试入口，按正常阶段顺序运行采集、治理、教育部科学新闻优先
   选题、文案生成/验证/审计、品牌 IP 视觉选择和 Comfly 生图。
2. 测试结果可以写入当前本地开发数据库和 MinIO；同时导出 `output/preview/<run-id>/` 下的
   JSON、图片和安全运行报告，便于前端读取和用户查看。不得修改已锁定的正式日结果。
3. 真实调用使用现有安全边界：新闻抓取的白名单和 10 天窗口、智谱结构化输出、文案失败
   最多一次自动修复、Comfly HTTPS/CDN 校验、图片尺寸和媒体类型校验、品牌资料引用边界。
4. 图片必须使用选中的公司 IP 参考图，最终输出通过现有图像校验并达到 `1024x1024`；若
   供应商或安全校验失败，预览报告展示 `review_required`/`failed` 和安全错误码，不伪造
   成功图片。
5. 在现有 frontend 应用中新增“真实预览”页面/面板，读取本地预览 manifest，展示：阶段
   状态、教育部新闻候选和链接、Top 1 解释、完整文案和标签、图片、品牌绑定、验证/审计
   问题、运行时间和失败原因。
6. 页面提供复制文案和下载图片/预览包能力，但不提供任何自动发布功能；文字和图片在移动
   与桌面尺寸下均不重叠。
7. 教育部科学政策优先规则必须版本化、可解释且有回归测试；历史每日选题不因规则更新而
   被改写。

## Acceptance Criteria

- [x] 预览入口能真实执行或明确报告第一个阻塞阶段，且每个阶段在本地 manifest 中有状态、
      时间、版本和安全错误信息。
- [x] 本地数据库中的每个阶段都有真实 run/job/package 状态和可追溯 ID，MinIO 中有成功图片
      对象；失败阶段不伪造成功状态。
- [x] 真实文案可读、面向家长，解释为什么学科学/科创/人工智能/机器人以及为什么在赛先生
      学，末尾含 `#赛先生科学` 和另外 1-2 个标签；验证、审计和修复次数可见。
- [x] 真实图片由公司 IP 参考图驱动，PNG 可打开且像素尺寸为 `1024x1024`；图片与文案在
      页面中同时可见，并可下载到本地。
- [x] 页面能展示成功、加载中和失败三类状态，不把 `review_required` 当成成功；不存在自动
      发布操作。
- [x] 直接科学教育政策/行动可在合格时优先于普通候选；教育部教材、会议和其他非科学政策
      新闻不获得该优先级，仍按普通评分排序。
- [x] `frontend-check`、相关后端测试和 `git diff --check` 通过；真实 API key、临时 CDN
      URL、原始模型响应和 MinIO 内部对象路径不进入页面或版本库。

## Out of Scope

- 不修改已锁定的正式日选题，不实现同日重算机制。
- 不放宽 Fake-IP、SSRF、HTTPS、域名白名单、尺寸或媒体类型校验。
- 本次预览不发送企业微信；正式分发阶段另行实现单人企业微信自建应用发送。朋友圈和其他
  社交平台自动发布仍不在范围内。
