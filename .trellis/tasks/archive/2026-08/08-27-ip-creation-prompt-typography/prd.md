# IP 创作页提示词与排版精修

## Goal

让 IP 视觉创作页能够接收不受产品层 2000 字限制的完整画面描述，同时把返回入口、创作简报、输出标签和 `01–03` 序号整理成更专业、统一、易读的编辑工作室排版。

## Background

- `frontend/src/features/ip-assets/IpAssetCreationPage.tsx:449-455` 的画面描述输入框设置了 `maxLength={2000}`。
- `backend/app/schemas/ip_assets.py:172-175` 的 IP 生图请求也设置了 2000 字上限，`backend/app/application/services/ip_assets.py:781` 还会经过共享图片提示词校验。
- 共享生成适配器会再次校验提示词；只删除输入框属性会导致长描述在提交或 worker 阶段失败。
- 真实 PostgreSQL 验证发现 `ip_asset_generation_jobs.prompt` 仍为 `varchar(2000)`；端到端取消限制需要升级为 `TEXT`，否则长描述会在持久化时失败。
- 当前创作页采用暖纸张、深青与陶土色的编辑工作室视觉。返回入口仍是普通文本链接，`01 / 创作简报`、`OUTPUT / 私人结果` 与参考胶片序号共用偏技术化的等宽字样，层级不够统一。

## Requirements

### R1 — IP 创作画面描述取消产品层字符数限制

- 删除画面描述输入框的 `minLength` 和 `maxLength`，仅保留必填；任意非空白长度的描述都可提交。
- IP 生图请求、入队校验和 worker/provider 适配路径都不得再以少于 8 字或超过 2000 字为由拒绝画面描述。
- 空白归一化、禁用视觉指令校验、请求指纹、幂等和 provider 自身可能返回的真实限制继续生效。
- 取消上限只作用于 IP 资产创作任务；公众号、素材包等其他共享生图调用继续使用现有 2000 字默认上限。
- 不增加字数计数器，不把“无限制”误写成 provider 能保证接受任意体积；基础 HTTP/运行时安全边界仍然有效。
- 使用 Alembic `20260827_0037` 将生成任务提示词升级为 `TEXT`；降级遇到超过 2000 字的数据时必须拒绝，不能截断。

### R2 — 专业化返回入口

- `/ip-assets/create` 顶部保留稳定的 `/ip-assets` 链接，不改成依赖浏览器历史的返回动作。
- 将普通文本链接升级为清晰的双层返回控件：可识别的方向图形、资产库上下文和中文主标签；整块保持原生链接语义、键盘焦点和至少 44px 触控高度。
- 控件与右侧退出登录在桌面和窄屏均不冲突，不引入外部图标或字体网络依赖。

### R3 — 创作简报、OUTPUT 与序号字体层级

- 将 `01 / 创作简报` 拆成可独立排版的编号和中文名称，使用清晰的无衬线小标题体系、tabular numerals 和克制字距。
- 将 `OUTPUT / 私人结果` 拆成输出标签、分隔规则和隐私说明，在深色输出舞台保持 AA 对比和专业层级。
- `01–03` 参考胶片编号与章节编号共享数字语言，但必须通过容器、尺寸和位置区分“章节”与“素材顺序”。
- 中文正文、主标题和功能标签保持各自明确字族角色；使用本地系统字体栈和已有色彩 token，不加载远程字体。
- 保持暖纸张＋深青编辑工作室方向，不重做页面结构，不增加无意义动画；窄屏和 reduced-motion 合同保持不变。

### R4 — Compatibility

- 保留参考图 1–3 张、个人结果、显式共享、生成幂等、真实队列状态和本地名片边界。
- 不修改共享图库、翻页相册、登录页、公众号工作台或根开发控制台。
- 更新相关组件/API/后端测试和 OpenAPI 生成合同，不手改生成的 TypeScript 类型。

## Acceptance Criteria

- [x] AC1: 画面描述 textarea 不再包含 `minlength` 或 `maxlength`，仍为 required；1 个非空白字符和超过 2000 个字符均可提交。
- [x] AC2: 任意非空白长度的 IP 生图请求可通过 API 模型、入队服务和 worker 适配前校验，完整归一化文本参与同一请求指纹并传给 provider。
- [x] AC3: 非 IP 的共享图片生成请求仍默认拒绝少于 8 字或超过 2000 字的提示词，禁用指令检查保持不变。
- [x] AC4: 返回共享图库入口具有图形、上下文副标签和中文主标签，原生链接、焦点和 44px 触控行为可访问。
- [x] AC5: 创作简报、OUTPUT/私人结果、章节 `01` 与胶片 `01–03` 具有可区分且统一的专业字体层级，桌面与 390px 宽度无溢出。
- [x] AC6: 现有创作页行为测试、axe、Prettier、ESLint、严格 TypeScript、后端焦点测试、OpenAPI drift 和生产构建通过。
- [x] AC7: 本地真实浏览器检查确认返回入口、简报标签、输出标签和参考序号在首屏清楚可见，页面服务仍可正常打开。

## Out of Scope

- 修改 provider 模型、provider 账号限额、请求体基础设施限制或生成质量策略。
- 自动改写/压缩长提示词、AI 提示词增强、字数统计、token 估算或费用预估。
- 重做创作页信息架构、共享图库、个人素材架或翻页相册。
- 引入外部字体 CDN、图标包、动画库或新的前端依赖。
