# 中国政府网要闻高优先级采集

## Goal

将中国政府网“要闻”列表纳入每日权威信息采集，使科技教育、前沿科技、硬科技和产业技术突破类要闻可以进入事实治理与选题池，并在满足既有主题规则时获得高可信来源优先级；普通政务、会议和与科技无关的要闻不得因为来源权威而无条件优先。

## Confirmed Facts

- 生产环境当前只有 `china-government-policy`，入口为 `/zhengce/zuixin/ZUIXINZHENGCE.json`，允许路径仅为 `/zhengce/`，因此无法发现 `/yaowen/liebiao/` 文章。
- 中国政府网要闻页从 `/yaowen/liebiao/YAOWENLIEBIAO.json` 加载 `TITLE`、`URL`、`DOCRELPUBTIME`；现有政府 JSON 连接器可安全解析相同字段，详情页正文位于 `.pages_content`。
- 目标文章 `content_7079251.htm` 在现行 `science-tech-editorial-v3-broad` 规则下为 `frontier_science_technology`，编辑优先分为 `0.86`，具有 `completed_progress`、`planned_or_in_progress` 和 `event_or_conference` 信号。
- 当前选题保留硬否决、0.59 普通阈值、Tier A/B 硬科技候选池和 LLM 同组精排；教育部实质性科技教育主题拥有独立的来源认证优先规则。

## Requirements

1. 新增独立的中国政府网要闻来源，使用固定 JSON 入口、`www.gov.cn` 主机白名单和 `/yaowen/liebiao/` 路径白名单；不得扩大现有政策来源的路径或把两个来源合并为一个可变配置。
2. 新来源等级为 Tier A，沿用当前 `science-tech-editorial-v3-broad` 采集相关性规则，只持久化科技教育、前沿科技或广义硬科技候选；普通政务、外事、救援、财政和农业新闻应被正常过滤。
3. 为新来源增加独立连接器身份和离线固定样例，复用政府 JSON 解析与安全详情抽取，不允许外部主机、非要闻路径、查询串或重定向绕过 allowlist。
4. 当前选题版本增加可回放的中国政府网要闻优先策略。只有同时满足以下条件时才进入优先组：事件包含该来源的真实 occurrence、通过当前科技主题 cohort、没有硬否决，并已按既有阈值或硬科技候选池规则成为 eligible。来源本身不得绕过主题门槛、硬否决、陈旧窗口或最终成功推送重复窗口。
5. 中国政府网合格主题与教育部合格主题位于受保护的优先组，LLM 仅可在同一优先组内按新闻价值、突破意义、科技教育相关性和传播价值排序；不得跨组把普通来源候选提升到优先主题之前。
6. 历史采集版本和 `.10` 及更早选题配置必须保持字面可回放；新行为使用新的来源版本/选题版本身份，不修改历史快照含义。
7. 发布后执行一次生产安全的来源同步与定向补采验证，确认目标文章形成候选和不可变快照并进入治理输入；不人工强制选中、不补发企业微信，也不绕过正常内容生产链路。

## Acceptance Criteria

- [x] 中国政府网要闻 JSON 中的目标文章可被发现、详情解析并通过 URL/主机/路径安全校验。
- [x] 目标文章按现行规则持久化为 Tier A 的前沿科技候选，保留快照、发布时间、规则版本、cohort、分数、原因和内容信号。
- [x] 同一列表中的普通政务新闻不会因为 Tier A 或来源优先策略进入合格主题优先组。
- [x] 一个拥有中国政府网要闻 occurrence 的合格且无否决事件排在普通 eligible 事件组之前；LLM 只能在同组调整次序。
- [x] 硬否决、不合格主题、未达到 eligibility 的中国政府网事件不能获得优先，也不能触发阈值绕过。
- [x] 连接器、采集集成、选题单元/仓储、配置回放和来源计数测试通过，历史配置测试保持不变。
- [x] 生产部署健康，定向补采可在数据库中确认目标 URL 的候选、快照和治理 lineage；不触发人工强制发布。

## Out of Scope

- 抓取中国政府网全部栏目、搜索结果或站外转载链接。
- 调整品牌 RAG、文案、配图、企业微信交付或微信公众号发布链路。
- 取消硬否决、重复窗口、陈旧事件规则，或让权威来源覆盖主题相关性判断。
