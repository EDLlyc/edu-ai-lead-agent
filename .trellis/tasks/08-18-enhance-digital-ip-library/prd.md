# 完善数字 IP 资产库

## Goal

把现有“品牌文档 RAG + 独立视觉素材目录”整理成一个适合 Agent 实习作品集展示的数字 IP 资产库，让使用者能够看到人设、文字规则、视觉资产、Agent 检索依据、人工反馈和基础评测之间的完整关系。

本任务只在本地代码与本地数据环境中实现，不部署服务器、不触发业务推送、不调用线上模型或供应商。

## Background and Confirmed Facts

- 当前品牌知识域已经支持定位、语气、优秀示例、禁用表达、安全规则、视觉规范等七类文档，入口见 `backend/app/domain/brand_knowledge.py:17-24`。
- `BrandUploadMetadata` 当前固定 `brand_slug=sai-xiansheng`、`language=zh-CN`，并维护受众、生效日期和文字/安全/视觉标签，见 `backend/app/domain/brand_knowledge.py:72-120`。
- 品牌资料已经具备私有原件、不可变版本、异步解析/切块/向量化、激活/停用和全文+向量混合检索；检索会过滤激活版本、受众、生效日期以及 embedding provider/model，见 `backend/app/infrastructure/db/brand_knowledge.py:897-1046`。
- 前端已支持资料上传、处理状态、版本激活/停用和生成上下文召回测试，但主要展示最新版本，且上传表单没有人物卡、视觉资产或反馈管理能力，见 `frontend/src/features/brand/BrandKnowledgePanel.tsx:26-263`。
- 视觉资产域已支持角色、动作、场景、用途、优先级、人工审核、checksum 和确定性选择，见 `backend/app/domain/visual_assets.py:177-345`；它当前没有与品牌知识工作台形成统一的数字 IP 视图。
- Agent Workbench 已通过只读 `retrieve_brand_context` Tool 消费品牌上下文，品牌内容始终不能作为外部事实证据，见 `backend/app/application/services/agent_tools.py:277-299`。
- 当前没有数字 IP 专项的召回质量、人设一致性、禁用表达命中率评测，也没有将人工采纳/拒绝反馈回收到受控 IP 资产的工作流。
- 现有工作区还有与本任务无关的用户修改；实现必须保留并避开这些内容。

## Requirements

### Product decision

- MVP 只完善现有“赛先生 + 小赛”这一套数字 IP，不建设任意新增 IP、租户或权限管理。
- 投影结构保留稳定 `profile_id`、角色标识和关联 ID，使后续可以增加其他 IP，而本轮不承担通用管理复杂度。

### R1. 数字 IP 人设卡

- 提供结构化人设视图，至少表达名称、角色定位、核心价值、性格/语气、常用表达、禁用表达、目标受众、适用渠道和版本状态。
- 人设卡必须与现有品牌文档、有效期和激活版本建立明确关联，而不是复制一套彼此漂移的规则文本。
- 默认展示现有赛先生/小赛资产，不伪造不存在的业务资料。

### R2. 文字与视觉资产关联

- 在一个数字 IP 视图中同时呈现相关品牌资料与已审核视觉资产。
- 复用现有 `VisualAssetCatalog`、审核状态、角色/动作/场景标签和 checksum，不重复实现素材解析与选择算法。
- 本轮不开放任意视觉文件上传；只读取和展示现有本地受控 manifest 的安全元数据，不向浏览器暴露私有路径或原图字节。

### R3. Agent 可解释检索

- 继续复用现有品牌混合检索及 `retrieve_brand_context` Tool。
- 结果需要展示文档/版本、资料类型、命中的语气/安全标签以及安全的分数或选择说明。
- 保持品牌知识与外部事实证据分离，任何数字 IP 内容都不得被标记为事实证据。

### R4. 人工反馈闭环

- 允许本地用户对一次品牌上下文召回或文案结果记录“采纳 / 不采纳”和一个受限原因。
- 反馈不得自动改写人设、自动激活版本或自动把生成内容加入优秀示例；升级为知识必须经过显式人工确认。
- 反馈只用于本地作品集与评测，不触发任何发布、推送或线上副作用。

### R5. 轻量数字 IP Eval

- 提供一组脱敏、确定性的本地案例，覆盖定位、语气、禁用表达、受众和视觉指导。
- 至少输出规则召回覆盖、禁用规则命中、品牌内容被误作事实证据的次数以及案例通过数。
- 报告必须区分确定性 fixture 结果和真实模型效果，禁止把 fixture 分数宣传成线上模型准确率。

### R6. 本地作品集体验

- 页面清楚展示“人设卡 → 品牌资料/视觉资产 → Agent 召回 → 反馈/评测”的关系。
- 保留无发布按钮、无业务推送、无任意 URL/代码执行的安全边界。
- UI 使用现有生成 API 类型和无障碍规范，不手写重复 wire type。

### R7. 实施与验证边界

- 仅本地实现，不 SSH、不部署、不调用 provider、不发送企业微信。
- 只运行与本任务直接相关的格式、类型和定向测试；不要求完整仓库测试套件。
- 不覆盖或提交本任务之外的现有工作区修改。

## Acceptance Criteria

- [ ] 本地页面能查看一个数字 IP 的结构化人设信息、关联品牌资料和已审核视觉资产。
- [ ] 用户可输入一个场景问题，看到复用现有混合检索产生的品牌上下文、来源版本、标签和 `evidence_eligible=false` 边界。
- [ ] 用户可对一次结果记录采纳/不采纳反馈；反馈不会自动修改或激活知识。
- [ ] 本地确定性 Eval 覆盖至少五类 IP 规则并生成稳定摘要，且品牌知识误作事实证据次数为零。
- [ ] Agent、UI 和 Eval 复用现有品牌检索/视觉资产契约，没有复制检索算法或事实证据类型。
- [ ] 本任务的定向后端、前端、类型、格式及契约测试通过。
- [ ] 无服务器部署、provider 调用、企业微信发送或业务数据变更。

## Out of Scope

- 生产部署、线上数据迁移或现有业务调度变更。
- 自动发布公众号、朋友圈或企业微信内容。
- 自动学习并直接修改人设规则。
- 任意图片上传、图片编辑、训练或微调模型。
- 将品牌知识与新闻事实证据合并。
- 完整 SaaS 权限、租户、计费或公开分享能力。
