# 评测：线上质量日报与选题标准答案集

## 背景（2026-09-28）

评测集中在旁支（IP 素材检索、公众号审稿、Workbench），每日主链路（抓取 → 选题 → 朋友圈文案 →
长图 → 企微推送）几乎没有评测；漏抓教育政策、卖点重复、长图截断、草稿失败都是人工发现的。用户确认先做：

1. **线上质量日报**：每天自动汇总前一天各环节结果与问题。
2. **选题标准答案集**：把运营明确说过“应该选 / 不该选”的新闻固化，每次改选题规则都能量化对比。

## 验收

- 日报只读（数据库只读事务），不重启、不修改任何线上服务；每天晚间推送后自动生成 Markdown + JSON。
- 日报覆盖：三个时段选题（含类型，如国家教育风向）、文案通过/修复/失败与问题码、近 7 天品牌片段复用、
  配图、企微正式推送、长图与补发、公众号草稿、抓取失败、模型 Token；异常用 🔴/🟡 标出。
- 标准答案集以真实运营标注为主，尽量使用线上真实的治理摘要/事实/分类；报告对比 `.11` 与当前 `.13`，
  `--check` 检测漂移；已知未解决的缺口保留在报告里，不为通过而隐藏。

## 不在本次范围

- 日报推送到企微群（需要用户指定运营群 webhook）。
- 根据答案集修改选题规则（发现的问题另行决策）。
